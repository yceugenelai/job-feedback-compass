# Feedback tag dictionary / フィードバックタグ辞書

Shared tags for feedback on positions. Format: `+<category>` (positive) / `-<category>` (negative).
求人へのフィードバック用の共通タグ。形式：`+<カテゴリ>`（ポジティブ）/ `-<カテゴリ>`（ネガティブ）。

**Any agent may add tags**: check that no similar tag exists, then append a row at the end.
This file is committed: **generic definitions only, never personal content** (statistics go to `workspace/shared/analysis/preference_model.md`).
**どのエージェントも追加可**：似たタグがないか確認してから末尾に追記。このファイルはコミットされるため、**一般的な定義のみ**を書き、個人的な内容は書かない。
